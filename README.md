# Fitlog — дневник тренировок

## Оконное приложение

Готовый файл: `dist/Fitlog.exe`. Это одиночный файл, Python для запуска не нужен.

Разделы:
- **Дневник**: календарь (дни с тренировками подсвечены) и тренировка за выбранный день.
  «Добавить упражнение» открывает справочник по группам мышц с поиском (можно добавить своё).
  Для упражнения по умолчанию даются 3 строки-подхода, строки можно добавлять и удалять.
  У каждого подхода есть тип: разминочный, рабочий или отказной. Рядом показаны те же подходы
  с прошлой и позапрошлой тренировки.
- **История**: список всех тренировок.
- **Прогресс**: рекорды и график по упражнению. Разминочные подходы в статистике не учитываются.

Запуск из исходников: `python run_gui.py` (нужен `pip install customtkinter`).

Пересборка exe:
```bash
pip install customtkinter pyinstaller pillow
python tools/make_icon.py
python -m PyInstaller --noconfirm --onefile --windowed --name Fitlog --icon assets/fitlog.ico ^
    --add-data "assets/fitlog.ico;assets" --collect-data customtkinter run_gui.py
```

## Версия для телефона (папка `web/`)

Веб-приложение, которое можно установить на iPhone как обычное приложение: работает без интернета,
данные хранятся на телефоне. Сборка не нужна, достаточно выложить содержимое `web/` на любой
статический хостинг с HTTPS (Netlify, GitHub Pages).

- Установка на iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- Перенос данных с компьютера: `python -m fitlog export fitlog.json`, затем отправить файл на телефон
  и в приложении открыть «Ещё» → «Загрузить из файла».
- Обратно: «Ещё» → «Сохранить копию в файл», затем `python -m fitlog import fitlog.json`.
- После изменения файлов в `web/` увеличь номер версии `CACHE` в `web/sw.js`, чтобы телефоны получили обновление.
- Проверить локально: `python -m http.server -d web 8000` и открыть http://localhost:8000.

## Консольная версия

Консольное приложение на Python (только стандартная библиотека). Данные хранятся в SQLite:
`~/.fitlog/fitlog.db`. Путь можно поменять переменной `FITLOG_DB` или флагом `--db`.

## Использование

```bash
# записать подходы (60 кг × 10 повторов × 3 подхода, потом 65×8)
python -m fitlog log "жим лёжа" 60x10x3 65x8
python -m fitlog log присед 100x5x5 --date вчера --note "хорошее самочувствие"

python -m fitlog list            # последние тренировки
python -m fitlog show 2026-10-04 # тренировка за день
python -m fitlog stats           # статистика по всем упражнениям
python -m fitlog stats "жим лёжа" # рекорды и история прогресса
python -m fitlog exercises       # список упражнений
python -m fitlog delete 2026-10-04
python -m fitlog export fitlog.json  # выгрузка для телефона (import — обратно)
```

Расчётный разовый максимум (1ПМ) считается по формуле Эпли: `вес × (1 + повторы / 30)`.
